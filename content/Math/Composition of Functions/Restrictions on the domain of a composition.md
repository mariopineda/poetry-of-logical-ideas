A monitoring system uses $f(x)=x^2-x-6$ and $g(u)=\frac{5}{u-4}-2$. Define $h=g\circ f$. Determine all real values excluded from the domain of $h$, and give the domain in set notation.

## Solution

> [!example]- Show solution
> The outer function requires $u\ne4$, so $f(x)\ne4$. Solve $x^2-x-6=4$, giving $x^2-x-10=0$. Thus $x=\frac{1\pm\sqrt{41}}2$. Therefore $\boxed{D_h=\{x\in\mathbb R:x\ne(1-\sqrt{41})/2,\ x\ne(1+\sqrt{41})/2\}}$.
