# Orthographic Views 4 - Unit Cube Model

The image shows a new solid built from identical unit cubes. **Draw its front, top, and right-side views.** For the top view, also draw a **mat plan** indicating the height of every occupied stack. Use the explicit **FRONT VIEW** and **RIGHT VIEW** markers beneath the model.

![[Orthographic-04-question.svg]]

## Solution

> [!example]- Show solution
> The three orthographic views and the numbered mat plan are shown below. Looking left-to-right, the front profile has heights **[3, 1, 1]**; looking from front to back, the right-side profile has heights **[1, 3]**. The top/mat plan is **[1, 1, 1]; [3, 0, 1]** (rows run front to back).
