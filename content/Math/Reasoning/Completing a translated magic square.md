A $3\times3$ number puzzle contains every integer from $2$ through $10$ exactly once. Every row, column and diagonal has the same sum. Complete this partially filled puzzle and justify the four unknown entries.

|  |  |  |
|:---:|:---:|:---:|
| $A$ | $2$ | $B$ |
| $4$ | $6$ | $8$ |
| $C$ | $10$ | $D$ |

## Solution

> [!example]- Show solution
> The integers sum to $54$, so each row totals $18$. The left-to-right diagonal and columns give $A=9$, $B=7$, $C=5$, and $D=3$. The completed square is $\begin{pmatrix}9&2&7\\4&6&8\\5&10&3\end{pmatrix}$. Each row, column and diagonal totals $18$.
