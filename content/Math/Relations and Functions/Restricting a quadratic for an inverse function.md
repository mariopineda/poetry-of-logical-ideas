A quadratic function is defined by $f(x)=-3(x+5)^2+12$. Give **two different maximal interval restrictions** on its domain that make its inverse a function. Justify each restriction using the horizontal-line test.

## Solution

> [!example]- Show solution
> The axis of symmetry is $x=-5$ and the vertex is $(-5,12)$. On either side of the vertex the parabola is strictly monotonic, so each restriction passes the horizontal-line test. The two maximal domain intervals are
>
> $$\boxed{(-\infty,-5]}\quad\text{and}\quad\boxed{[-5,\infty)}.$$
>
> Both include the vertex, and either can be used separately to define an inverse function.
