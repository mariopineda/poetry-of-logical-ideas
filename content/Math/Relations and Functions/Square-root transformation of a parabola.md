The graph shows a downward-opening parabola $y=f(x)$. Let $g(x)=\sqrt{f(x)}$. Without using graphing technology:

1. Compare the $x$-intercepts of $f$ and $g$.
2. Compare their $y$-intercepts.
3. State the real domain of $g$.

Use the given graph and explain why every conclusion follows.

![[diploma-batch03-2017-mc12-parabola.svg]]

## Solution

> [!example]- Show solution
> Read the key features from the plotted parabola: it crosses the $x$-axis at $x=-3$ and $x=3$, and it crosses the $y$-axis at $(0,9)$. The graph is consistent with $f(x)=9-x^2$. The square-root function $g(x)=\sqrt{f(x)}$ vanishes if and only if $f(x)=0$; therefore the $x$-intercepts stay at $\boxed{(-3,0),(3,0)}$.
>
> At $x=0$, $f(0)=9$ but $g(0)=\sqrt9=3$, so the $y$-intercept changes from $(0,9)$ to $\boxed{(0,3)}$. Finally $g$ is real only where $f(x)\ge0$:
>
> $$9-x^2\ge0\quad\Longleftrightarrow\quad\boxed{-3\le x\le3}.$$
>
> The endpoints belong to the domain because $\sqrt0$ is defined.
