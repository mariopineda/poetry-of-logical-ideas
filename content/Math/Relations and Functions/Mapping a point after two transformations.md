A function $f$ contains the point $(-4,6)$. Let

$$g(x)=3f\!\left(-\frac{x+2}{2}\right)-5.$$

Determine the corresponding point on $g$, showing the horizontal and vertical coordinate calculations.

## Solution

> [!example]- Show solution
> Set the input of $f$ equal to $-4$:
>
> $$-\frac{x+2}{2}=-4\implies x=6.$$
>
> Then $y=3(6)-5=13$, so the image is $(6,13)$.
>
