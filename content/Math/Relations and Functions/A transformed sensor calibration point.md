A sensor's calibration curve is represented by $y=f(x)$ and contains the point $(-2,5)$. A second calibration curve is defined by $g(x)=3f(2x-4)+1$. Determine the corresponding point on the graph of $g$, and explain each coordinate change.

## Solution

> [!example]- Show solution
> The input of $f$ must equal $-2$: $2x-4=-2$, giving $x=1$. The new output is $3(5)+1=16$. Thus the corresponding point is $\boxed{(1,16)}$. The horizontal coordinate changes by solving the inside transformation, while the vertical coordinate is multiplied by $3$ and increased by $1$.
