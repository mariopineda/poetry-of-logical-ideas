A point $(-2,7)$ lies on the graph of $y=f(x)$. The transformed function is

$$g(x)=-2f(5x-10)+4.$$

Find the corresponding point on $g$. Show your horizontal and vertical calculations.

## Solution

> [!example]- Show solution
> Set the input of $f$ equal to $-2$: $5x-10=-2$, so $x=8/5=1.6$. The output is $-2(7)+4=-10$. The image point is $\boxed{(1.6,-10)}$.
