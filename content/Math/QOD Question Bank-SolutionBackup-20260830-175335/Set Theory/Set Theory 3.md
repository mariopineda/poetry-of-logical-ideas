## Question

1. Draw a Venn diagram to illustrate this information.
2. List the elements of $A \cap B$
3. List the elements of $A \cup B$
4.  List the elements of $\setminus A$ 
5.  List the elements of $\setminus(A \cup B)$
6.  List the elements of $\setminus(A \cap B)$
