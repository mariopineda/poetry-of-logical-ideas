## Question

Divide.

1. $$\frac{4x+8}{2}$$
2. $$\frac{9x+12}{3}$$
3. $$\frac{6x^2+4x-8}{2}$$
4. $$\frac{10x^2-15x}{5x}$$

## Solution

1. $$\frac{4x+8}{2} = \frac{4x}{2}+\frac{8}{2} = 2x+4$$
2. $$\frac{9x+12}{3} = \frac{9x}{3}+\frac{12}{3} = 3x+4$$
3. $$\frac{6x^2+4x-8}{2} = \frac{6x^2}{2}+\frac{4x}{2}-\frac{8}{2} = 3x^2+2x-4$$
4. $$\frac{10x^2-15x}{5x} = \frac{10x^2}{5x}-\frac{15x}{5x} = 2x-3$$
