A research lab labels specimens with a fixed letter **K** followed by **five digits**. The first digit must be 1, 2, or 3. Each of the other four digits can be 0 through 9, and repetitions are permitted.

Determine the number of possible identifiers and explain the number of choices for each position.

## Solution

> [!example]- Show solution
> The letter K is fixed, giving one choice. The first digit has three possibilities. Each of the four remaining positions has ten independent choices.
>
> $$N=1\times3\times10\times10\times10\times10=\boxed{30\,000}.$$
>
> Repetition is allowed, so later positions still have ten choices even if a digit has already appeared.
