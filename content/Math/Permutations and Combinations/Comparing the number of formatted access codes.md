One access-code format uses three letters followed by four digits. A second uses five letters followed by four digits. Each letter is chosen from a set of 22 permitted letters, and each digit from 0 to 9; repetition is allowed. How many times as many codes does the second format permit? Justify your ratio.

## Solution

> [!example]- Show solution
> With repetition permitted, the shorter code has $22^3\cdot10^4$ possible strings and the longer code has $22^5\cdot10^4$. Taking the ratio cancels the digits and three common letter positions:
>
> $$\frac{22^5\cdot10^4}{22^3\cdot10^4}=22^{5-3}=\boxed{484}.$$
>
> The ratio, rather than either raw total, is what the question asks.
