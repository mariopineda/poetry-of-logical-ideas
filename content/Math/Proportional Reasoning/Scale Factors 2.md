## Question

Complete the following table. Do not answer with decimals unless the given scale factor is a decimal.

| LSF | ASF | SASF | VSF |
| --- | --- | --- | --- |
| 3:1 |  |  |  |
|  | 1:4 |  |  |
|  |  |  | 1:125 |
|  |  | 16 |  |
| $\displaystyle\frac{5}{2}$ |  |  |  |
|  |  |  | $\displaystyle\frac{27}{8}$ |
| 0.3 |  |  |  |
|  |  | 25 |  |
|  |  |  | $\displaystyle\frac{1}{1000}$ |

## Solution

| LSF | ASF | SASF | VSF |
| --- | --- | --- | --- |
| $3:1$ | $3^2 : 1^2 = 9:1$ | $9:1$ | $3^3 : 1^3 = 27:1$ |
| $1 : \sqrt{4} = 1:2$ | $1:4$ | $1:4$ | $1^3:2^3 = 1:8$ |
| $\sqrt[3]{1} : \sqrt[3]{125} = 1:5$ | $1^2 : 5^2 = 1:25$ | $1:25$ | $1:125$ |
| $\sqrt{16} = 4$ | $16$ | $16$ | $4^3 = 64$ |
| $\displaystyle\frac{5}{2}$ | $\left(\displaystyle\frac{5}{2}\right)^2 = \displaystyle\frac{25}{4}$ | $\displaystyle\frac{25}{4}$ | $\left(\displaystyle\frac{5}{2}\right)^3 = \displaystyle\frac{125}{8}$ |
| $\sqrt[3]{\displaystyle\frac{27}{8}} = \displaystyle\frac{3}{2}$ | $\left(\displaystyle\frac{3}{2}\right)^2=\displaystyle\frac{9}{4}$ | $\displaystyle\frac{9}{4}$ | $\displaystyle\frac{27}{8}$ |
| $0.3$ | $0.3^2=0.09$ | $0.09$ | $0.3^3=0.027$ |
| $\sqrt{25}=5$ | $25$ | $25$ | $5^3=125$ |
| $\sqrt[3]{\displaystyle\frac{1}{1000}} = \displaystyle\frac{1}{10}$ | $\left(\displaystyle\frac{1}{10}\right)^2 = \displaystyle\frac{1}{100}$ | $\displaystyle\frac{1}{100}$ | $\displaystyle\frac{1}{1000}$ |
