Complete the following table. Express all scale factors as ratios (either as $a:b$ or as $\frac{\displaystyle a}{\displaystyle b}$).


|     | LSF    | ASF    | SASF     | VSF     |
| --- | --- | --- | --- | --- |
| 1.  | $3:1$    |     |     |     |
| 2.  |     | $1:4$    |     |     |
| 3.  |     |     |     | $1:125$    |
| 4.  |                                      |     | $16$    |     |
| 5.  | $\frac{\displaystyle 5}{\displaystyle 2}$ |     |     |     |
| 6.  |                                      |     |     | $\frac{\displaystyle 27}{\displaystyle 8}$    |
| 7.  | $3:10$                                |     |     |     |
| 8.  |     |     | $25$    |     |
| 9.  |     |     |     | $\frac{\displaystyle 1}{\displaystyle 1000}$    |

## Solution

> [!example]- Show solution
>
> For similar three-dimensional objects,
>
> $$
> \text{ASF}=\text{SASF}=(\text{LSF})^2
> $$
>
> and
>
> $$
> \text{VSF}=(\text{LSF})^3.
> $$
>
> The completed table is:
>
> |  | LSF | ASF | SASF | VSF |
> | --- | --- | --- | --- | --- |
> | 1 | $3:1$ | $9:1$ | $9:1$ | $27:1$ |
> | 2 | $1:2$ | $1:4$ | $1:4$ | $1:8$ |
> | 3 | $1:5$ | $1:25$ | $1:25$ | $1:125$ |
> | 4 | $4:1$ | $16:1$ | $16:1$ | $64:1$ |
> | 5 | $\frac52$ | $\frac{25}{4}$ | $\frac{25}{4}$ | $\frac{125}{8}$ |
> | 6 | $\frac32$ | $\frac94$ | $\frac94$ | $\frac{27}{8}$ |
> | 7 | $3:10$ | $9:100$ | $9:100$ | $27:1000$ |
> | 8 | $5:1$ | $25:1$ | $25:1$ | $125:1$ |
> | 9 | $1:10$ | $1:100$ | $1:100$ | $1:1000$ |
