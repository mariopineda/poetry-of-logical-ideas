# Exponential Functions Practice T3 Q03 - Graphically Solving Exponential Equalities

Use graphing technology to find every real solution to the nearest tenth.

a) $8^{1-x}=2^{x+3}$; b) $3^{2x}=5^x$; c) $2^{x+2}=4^x+2$; d) $6^{x-1}=(1/3)^{x+2}$.

## Solution

> [!example]- Show solution
> a) $x=0$; b) $x=0$; c) set $u=2^x$: $u^2-4u+2=0$, so $u=2\pm\sqrt2$ and $x\approx-0.8$ or $x\approx1.8$; d) $x=\ln(2/3)/\ln(18)\approx-0.1$. Use graph intersections and verify each solution.
