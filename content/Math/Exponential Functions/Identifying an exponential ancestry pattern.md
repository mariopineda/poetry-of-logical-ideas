A computer simulation starts with **3 cells at stage 0**. At each new stage, every existing cell generates one new cell, so the number of cells doubles. The first counts are $3,6,12,24,\ldots$.

Identify which model family—**linear, quadratic, sinusoidal, or exponential**—best describes these data, write a function of stage $n$, and explain why a linear model would not fit.

## Solution

> [!example]- Show solution
> The ratios are constant:
>
> $$\frac63=\frac{12}{6}=\frac{24}{12}=2.$$
>
> This is an **exponential** pattern. The initial amount is $3$ and the stage multiplier is $2$:
>
> $$\boxed{N(n)=3(2^n)},\qquad n=0,1,2,\ldots.$$
>
> A linear model would have constant first differences, but the differences here are $3,6,12,\ldots$, which double. Check $N(0)=3$, $N(1)=6$, and $N(3)=24$.
