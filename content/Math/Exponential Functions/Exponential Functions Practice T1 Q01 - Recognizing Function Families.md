# Exponential Functions Practice T1 Q01 - Recognizing Function Families

The six graphs in the figure represent linear, quadratic, cubic, or exponential functions. Identify the function family of each graph and explain which features distinguish exponential functions from polynomial functions.

![[EF_T1_Q01.png]]

## Solution

> [!example]- Show solution
> a: linear; b: exponential growth; c: quadratic; d: cubic; e: exponential decay; f: quadratic. Exponential curves remain above the horizontal axis and approach $y=0$ at one end.
