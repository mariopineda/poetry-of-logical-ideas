# Exponential Functions Practice T4 Q10 - Declining Weekly Resource Output

A small production site initially produces $4200$ units per week. Output decreases $12\%$ each operating week. a) Write the exponential model. b) Determine output at week 20, nearest unit. c) Find when weekly output falls below 6 units, to nearest tenth of a week.

## Solution

> [!example]- Show solution
> Model $Q(t)=4200(0.88)^t$. At week 20, $Q\approx326$ units. Threshold $t=\ln(6/4200)/\ln(0.88)\approx51.2$ weeks.
