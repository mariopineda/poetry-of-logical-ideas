A function $f(x)=2^{x-1}-5$ is changed to $g(x)=4f(x)$. Identify **two** of the following features that remain unchanged: domain, range, $x$-intercept, $y$-intercept, and horizontal asymptote. Explain why each selected feature stays the same.

## Solution

> [!example]- Show solution
> Multiplying a function by a nonzero constant changes **outputs**, not admissible inputs, so both $f(x)=2^{x-1}-5$ and $g(x)=4f(x)$ have domain $\boxed{\mathbb R}$.
>
> An $x$-intercept occurs where the output is zero: $g(x)=4f(x)=0$ if and only if $f(x)=0$. Thus the $x$-intercept is unchanged and is
>
> $$2^{x-1}-5=0\;\Longrightarrow\;\boxed{x=1+\log_2 5}.$$
>
> The other three features change: the range is multiplied from $(-5,\infty)$ to $(-20,\infty)$, the horizontal asymptote changes from $y=-5$ to $y=-20$, and the $y$-intercept changes from $-9/2$ to $-18$. Thus the two invariant characteristics are **domain** and **$x$-intercept**.
