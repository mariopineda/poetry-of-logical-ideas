# Exponential Functions Practice T1 Q09 - Matching Equations to Exponential Plots

Match each equation to one of the six graphs. Explain how the intercept and growth/decay rate guided each match.

i. $y=3(0.65)^x$; ii. $y=2(3)^x$; iii. $y=5(0.4)^x$; iv. $y=4(1.7)^x$; v. $y=6(1.15)^x$; vi. $y=4^x$.

![[EF_T1_Q09.png]]

## Solution

> [!example]- Show solution
> i → graph 4; ii → graph 2; iii → graph 1; iv → graph 6; v → graph 3; vi → graph 5. Match at $x=0$ first, then compare the base.
