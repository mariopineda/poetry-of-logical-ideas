# Exponential Functions Practice T1 Q07 - Predicting Complete Function Properties

Without first graphing, make a table identifying the base, $y$-intercept, end behaviour, growth/decay, domain, range and number of $x$-intercepts of each function. Then verify using technology.

a) $y=4(3)^x$; b) $y=6(0.4)^x$; c) $y=3(1/6)^x$; d) $y=(3/4)(1/5)^x$; e) $y=18(1.6)^x$; f) $y=5(2.5)^x$; g) $y=7(0.2)^x$; h) $y=2.5(1/7)^x$.

## Solution

> [!example]- Show solution
> Bases: $3,0.4,1/6,1/5,1.6,2.5,0.2,1/7$. Intercepts: $4,6,3,3/4,18,5,7,2.5$. Growth: a,e,f. Decay: b,c,d,g,h. All have domain $\mathbb R$, range $y>0$ and no $x$-intercepts. Growth approaches zero on the left; decay approaches zero on the right.
