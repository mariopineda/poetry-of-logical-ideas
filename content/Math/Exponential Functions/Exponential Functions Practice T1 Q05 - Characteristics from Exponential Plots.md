# Exponential Functions Practice T1 Q05 - Characteristics from Exponential Plots

For each plotted exponential function, record the number of $x$-intercepts, $y$-intercept, end behaviour, domain and range.

![[EF_T1_Q05.png]]

## Solution

> [!example]- Show solution
> All have zero $x$-intercepts, domain $\mathbb R$, range $y>0$. Intercepts: a $6$, b $3$, c $8$, d $4$. Graphs a and c decrease; graphs b and d increase.
