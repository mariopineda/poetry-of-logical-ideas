# Exponential Functions Practice T1 Q02 - Reading Exponential Graph Characteristics

Use only the exponential graphs from [[Exponential Functions Practice T1 Q01 - Recognizing Function Families]]. For each, identify the number of $x$-intercepts, $y$-intercept, end behaviour, domain, and range.

## Solution

> [!example]- Show solution
> Graph b: $y$-intercept $1$; graph e: $y$-intercept $3$. Both: no $x$-intercepts, domain $(-\infty,\infty)$, range $(0,\infty)$. As $x\to-\infty$, b approaches $0$ while e grows without bound; as $x\to\infty$, b grows without bound while e approaches $0$.
