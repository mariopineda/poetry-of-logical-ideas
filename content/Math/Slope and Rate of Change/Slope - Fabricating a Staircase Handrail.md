# Slope - Fabricating a Staircase Handrail

A metal fabricator is manufacturing a second handrail for an existing staircase. Both handrails must have identical slopes. All coordinates are measured in metres in the same side-elevation coordinate system.

| Handrail | First endpoint | Second endpoint |
|---|---|---|
| Original | $A(-2,1.1)$ | $B(2,3.3)$ |
| Configuration 1 | $(-1.5,0.8)$ | $(1.5,2.45)$ |
| Configuration 2 | $(-1.5,0.8)$ | $(2.5,2.45)$ |

![[Slope - Fabricating a Staircase Handrail - Diagram.png]]

**a)** Determine the slope of the existing handrail.

**b)** Determine which proposed configuration has the correct inclination.

**c)** Both configurations have the same vertical rise. Explain why their slopes differ.

> [!info]- Hint 1
> The two proposals have the same rise. Examine the horizontal distances before comparing them.

## Solution

> [!example]- Show solution
> **(a)** Determine the original handrail's signed rise and run from its endpoints.
>
> $$m_{AB}=\frac{3.3-1.1}{2-(-2)}=\frac{2.2}{4}=0.55$$
>
> **(b)** Calculate both proposed slopes.
>
> $$m_1=\frac{2.45-0.8}{1.5-(-1.5)}=\frac{1.65}{3}=0.55$$
>
> $$m_2=\frac{2.45-0.8}{2.5-(-1.5)}=\frac{1.65}{4}=0.4125$$
>
> Configuration 1 has the correct inclination because its slope equals the original slope of $0.55$.
>
> **(c)** Both configurations rise $1.65$ m. Configuration 1 has a run of $3$ m; configuration 2 has a run of $4$ m. The same rise over a longer run produces a smaller positive slope.
