# Slope - Warehouse Package Transfer System

An automated warehouse uses horizontal conveyors, vertical lifts and inclined conveyors to move packages between levels. A package travels through the following locations, in order. Both coordinates are measured in metres.

$$A(-6,1),\quad B(0,1),\quad C(0,5),\quad D(8,7)$$

![[Slope - Warehouse Package Transfer System - Diagram.png]]

**a)** Determine the slope of each section of the package’s journey.

**b)** Identify which section represents the vertical lift.

**c)** A technician claims the vertical lift has a slope of zero because its horizontal position does not change. Explain why this is incorrect.

> [!info]- Hint 1
> Distinguish no change in elevation from no change in horizontal position.

## Solution

> [!example]- Show solution
> **(a)** Find the signed rise and run for each pair of successive points.
>
> $$m_{AB}=\frac{1-1}{0-(-6)}=\frac{0}{6}=0$$
>
> For $BC$, the rise is $5-1=4$ m and the run is $0-0=0$ m. The slope would require division by zero, so it is **undefined**.
>
> $$m_{CD}=\frac{7-5}{8-0}=\frac{2}{8}=0.25$$
>
> **(b)** $BC$ is the vertical lift. The horizontal coordinate remains $0$ m while the package rises $4$ m.
>
> **(c)** The technician has confused zero rise with zero run. $AB$ has zero rise and nonzero run, giving zero slope. $BC$ has nonzero rise but zero run. Division by zero is undefined; a vertical line does not have slope zero.
