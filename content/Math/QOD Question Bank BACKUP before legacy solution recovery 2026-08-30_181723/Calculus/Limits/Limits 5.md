## Question

For the piecewise function $f(x ) =
\begin{cases}
x^2-2 & \mbox{, if } x<0 \\
1 & \mbox{, if } 0 \leq x<3 \\
4-x & \mbox{, if } x \geq 3
\end{cases}$

1. Algebraically determine whether $f(x)$ is continuous at $x=0,3$.
2. Sketch the function.
