An industrial light sensor uses the base-10 scale

$$L=\log_{10}\left(\frac{I}{I_0}\right),$$

where $I_0$ is a fixed reference intensity. One signal registers $L=7.3$. Another signal has **exactly one-eightieth of the first signal's intensity**. Find the second signal's level to the nearest tenth, explaining how the intensity ratio changes the logarithmic reading.

## Solution

> [!example]- Show solution
> If the first signal has intensity $I_1$ and level $7.3$, then
>
> $$7.3=\log_{10}(I_1/I_0).$$
>
> The second has intensity $I_2=I_1/80$. Subtract the logarithmic readings:
>
> $$\begin{aligned}
> L_2&=\log_{10}\left(\frac{I_2}{I_0}\right)\\
> &=\log_{10}\left(\frac{I_1}{80I_0}\right)\\
> &=\log_{10}\left(\frac{I_1}{I_0}\right)-\log_{10}80\\
> &=7.3-\log_{10}80\\
> &\approx7.3-1.90309=5.39691.
> \end{aligned}$$
>
> Rounded to the nearest tenth, the new reading is $\boxed{L_2=5.4}$. This correctly decreases when intensity decreases.
