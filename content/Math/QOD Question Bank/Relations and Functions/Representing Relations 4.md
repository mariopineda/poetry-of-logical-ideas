## Question

Determine the missing values in the table.

1. $y$ is three less than double $x$.

   |  |  |
   | --- | --- |
   | $x$ | $y$ |
   | $-2$ |  |
   | $0$ |  |
   |  | $-7$ |
   |  | $17$ |
2.

$$
y=-\frac{1}{2}x+6
$$

   |  |  |
   | --- | --- |
   | $x$ | $y$ |
   | $-15$ |  |
   | $2$ |  |
   |  | $0$ |
   |  | $-4$ |

## Solution

> [!example]- Show solution
>
> ### 1.
>
> "Three less than double $x$" means
>
> $$
> y=2x-3.
> $$
>
> Thus the completed table is
>
> | $x$ | $y$ |
> | ---: | ---: |
> | $-2$ | $-7$ |
> | $0$ | $-3$ |
> | $-2$ | $-7$ |
> | $10$ | $17$ |
>
> ### 2.
>
> For
>
> $$
> y=-\frac12x+6,
> $$
>
> the completed table is
>
> | $x$ | $y$ |
> | ---: | ---: |
> | $-15$ | $\frac{27}{2}$ |
> | $2$ | $5$ |
> | $12$ | $0$ |
> | $20$ | $-4$ |
