## Question

Determine the **domain and range** of the following functions in both **set notation** and **interval notation**.

![[Domain and range.png]]

## Solution

> [!example]- Show solution
>
> ### 7)
>
> The graph has an **open endpoint at $(0,4)$** and continues indefinitely down and to the left.
>
> **Domain**
>
> - Set notation: $\{x \in \mathbb{R} \mid x < 0\}$
> - Interval notation: $(-\infty,0)$
>
> **Range**
>
> - Set notation: $\{y \in \mathbb{R} \mid y < 4\}$
> - Interval notation: $(-\infty,4)$
>
> Because the point $(0,4)$ is open, neither $x=0$ nor $y=4$ is included.
>
> ---
>
> ### 8)
>
> The graph begins at the **closed point $(-4,-2)$** and continues indefinitely to the right.
>
> **Domain**
>
> - Set notation: $\{x \in \mathbb{R} \mid x \geq -4\}$
> - Interval notation: $[-4,\infty)$
>
> **Range**
>
> - Set notation: $\{y \in \mathbb{R} \mid y \geq -2\}$
> - Interval notation: $[-2,\infty)$
>
> The smallest value of $x$ is $-4$, and it is included. The minimum value of $y$ is $-2$, and it is also included. The arrow shows that the graph continues upward without bound.
>
> ---
>
> ### 9)
>
> The graph has **open endpoints at $(-2,2)$ and $(2,0)$**, with a minimum point at $(0,-3)$.
>
> **Domain**
>
> - Set notation: $\{x \in \mathbb{R} \mid -2 < x < 2\}$
> - Interval notation: $(-2,2)$
>
> **Range**
>
> - Set notation: $\{y \in \mathbb{R} \mid -3 \leq y < 2\}$
> - Interval notation: $[-3,2)$
>
> The endpoint values $x=-2$ and $x=2$ are not included because both endpoints are open. The minimum value $y=-3$ is included, while the maximum value $y=2$ is not included.
>
> ---
>
> ### Final Answers
>
> | Graph | Domain — Set Notation | Domain — Interval Notation | Range — Set Notation | Range — Interval Notation |
> | --- | --- | --- | --- | --- |
> | **7** | $\{x \in \mathbb{R} \mid x < 0\}$ | $(-\infty,0)$ | $\{y \in \mathbb{R} \mid y < 4\}$ | $(-\infty,4)$ |
> | **8** | $\{x \in \mathbb{R} \mid x \geq -4\}$ | $[-4,\infty)$ | $\{y \in \mathbb{R} \mid y \geq -2\}$ | $[-2,\infty)$ |
> | **9** | $\{x \in \mathbb{R} \mid -2 < x < 2\}$ | $(-2,2)$ | $\{y \in \mathbb{R} \mid -3 \leq y < 2\}$ | $[-3,2)$ |
