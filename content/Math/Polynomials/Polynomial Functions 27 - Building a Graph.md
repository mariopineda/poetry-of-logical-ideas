## Question

A quadratic function has:

- An absolute maximum at $(1,4)$.
- $x$-intercepts at $(-1,0)$ and $(3,0)$.
- A $y$-intercept at $(0,3)$.

1. Sketch a smooth graph that satisfies these characteristics. Label all four given points and show arrows at both ends.

2. State the domain and range using set notation.

3. State the sign of the leading coefficient and the value of the constant term. Explain how the graph tells you each answer.

4. Describe the end behaviour using quadrants. Explain why the turning point is an **absolute maximum**.

No calculator is required.

## Solution

> [!example]- Show solution
>
> ### 1. Sketch
>
> ![[Polynomial Functions 27 Solution Graph.png]]
>
> The parabola opens downward, is symmetric about $x=1$, and passes through all four labelled points. Both ends continue downward.
>
> For reference, its equation is
>
> $$
> y=-(x-1)^2+4=-x^2+2x+3.
> $$
>
> Students do not need to determine this equation.
>
> ### 2. Domain and range
>
> $$
> D=\{x\mid x\in\mathbb{R}\},\qquad
> R=\{y\mid y\leq4,\ y\in\mathbb{R}\}.
> $$
>
> ### 3. Leading coefficient and constant term
>
> The leading coefficient is **negative** because the parabola opens downward. The constant term is $3$ because the $y$-intercept is $(0,3)$.
>
> ### 4. End behaviour and maximum
>
> $$
> Q_{\mathrm{III}}\longrightarrow Q_{\mathrm{IV}}.
> $$
>
> Both ends extend downward. The turning point $(1,4)$ is an **absolute maximum** because $4$ is the greatest $y$-value anywhere on the graph.
