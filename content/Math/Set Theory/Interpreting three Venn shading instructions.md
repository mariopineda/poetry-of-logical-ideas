The three diagrams below use overlapping sets $H$ and $J$ within a universal set $U$. **Grey regions are shaded.**

![[batch09-venn-shading.svg]]

Write **a set expression** in $H$, $J$, union, intersection and complement for each diagram A, B and C. Justify your expressions by identifying the elementary Venn regions that are shaded. Do not select from an answer list.

## Solution

> [!example]- Show solution
> **Diagram A:** Only the region outside both circles is shaded, so $\boxed{(H\cup J)^\prime}$.
>
> **Diagram B:** Only the lens common to both circles is shaded, so $\boxed{H\cap J}$.
>
> **Diagram C:** Everything except the $H$-only region is shaded (the full circle $J$ and the outside of $H$), so $\boxed{H^\prime\cup J}$.
>
> A region-by-region check confirms that C contains $J$-only, the overlap, and neither; it excludes only $H$-only.
