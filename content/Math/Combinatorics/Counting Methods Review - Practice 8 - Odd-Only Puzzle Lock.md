A puzzle lock has **four ordered dials**. Each dial shows an integer from **00 to 39 inclusive**, and dial values may repeat.

How many lock codes contain **only odd numbers** on all four dials?

## Solution

> [!example]- Show solution
>
> There are 20 odd numbers among 0 through 39: 1, 3, 5, ..., 39. Each dial has 20 independent choices, and repetition is allowed:
>
> $$20^4=\boxed{160\,000}.$$
