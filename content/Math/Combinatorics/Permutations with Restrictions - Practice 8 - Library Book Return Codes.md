A university library prints labels made of:

- a **branch symbol**, either **E** or **W**;
- **two letters**, each chosen from 25 permitted letters (repetition allowed);
- **three digits**, each chosen from 0 through 9 (repetition allowed).

How many distinct labels can be printed?

## Solution

> [!example]- Show solution
>
> There are 2 branch symbols, 25 choices for each letter, and 10 for each digit. The positions are independent:
>
> $$2\cdot25^2\cdot10^3=\boxed{1\,250\,000}.$$
