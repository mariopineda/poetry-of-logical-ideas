Eight identical coins are flipped. Exactly **three show heads** and **five show tails**.

How many different H/T sequences can result? Treat coins with the same face as indistinguishable.

## Solution

> [!example]- Show solution
>
> The eight positions contain 3 identical H symbols and 5 identical T symbols. Count all permutations, then divide by arrangements that only exchange identical symbols:
>
> $$\frac{8!}{3!5!}=\binom83=\boxed{56}.$$
