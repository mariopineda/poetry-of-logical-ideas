An assessment contains **12 true/false questions**, and its answer pattern must contain **exactly seven T** responses and **five F** responses.

How many different answer patterns are possible?

## Solution

> [!example]- Show solution
>
> Choose which five of the 12 positions have the F response (or which seven have T):
>
> $$\frac{12!}{7!5!}=\binom{12}5=\boxed{792}.$$
